AmiGmail locale support
English is the only built-in language.
Install deutsch/AmiGmail.catalog below PROGDIR:Catalogs/deutsch/ or LOCALE:Catalogs/deutsch/.
AmiGmail.cd is the catalog description; deutsch/AmiGmail.ct is the German translation source.
The application uses locale.library V38+ and falls back to English if no matching catalog exists.
Entries marked "Internal UTF-8 path" preserve the already tested internal error/status byte encoding.
